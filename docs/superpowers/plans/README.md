# Implementation Plans

This directory separates active implementation work from historical execution records.

- `active/` contains only plans that are currently approved for implementation.
- `archive/` contains completed, superseded, or historical plans kept for design archaeology and regression/debugging context.

Archived plans are **not** evidence that their unchecked tasks are still pending. Project status and milestone order come from `ROADMAP.md`.

When a design is approved and implementation is ready to begin, create a focused plan under `active/`. When that plan is completed or superseded, move it to `archive/` instead of deleting it.
